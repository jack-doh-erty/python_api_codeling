# Project guidance

This project is a learning environment for building APIs in Python as part of a Codeling course.

When working in this repository:

- Give verbose, educational explanations of implementation choices, API concepts, test results, errors, and debugging steps. Assume the purpose is to learn, not merely to obtain a finished solution.
- Keep all implementation and explanations within the scope of the current lesson. Do not introduce features, refactors, abstractions, or unrelated improvements from later lessons.
- Preserve the learner's existing work and make the smallest change that satisfies the lesson requirements.
- Use the Codeling CLI to submit completed solutions and report course progress in the Codeling UI.
- Run relevant checks or tests before submitting, and clearly explain any failures or missing tests.
